  ✓ API (G3)         - Average Performance Index
  ✓ RTC/km           - Race Time Comparison per kilometer

  ✓ Trainer_Place_%  - Trainer place percentage
  ✓ W-P-S stats      - Various condition breakdowns
  ✓ DOD              - Date of data

  ✓ Hist_Prize_Won   - Prize money for this race
  ✓ Hist_Winner      - Winning dog name
